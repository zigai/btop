# btop

A fork of [btop](https://github.com/aristocratos/btop), the terminal resource monitor.

## Features

- **proc-columns**: the process table gets a `cwd` column, column widths you can drag to resize or set in config (`proc_column_*`), headings you click to sort, and a `proc_width_percent` setting for the box width. Sort values `program` and `arguments` are renamed to `name` and `command`. Upstream status: fork only.
